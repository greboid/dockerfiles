# melange patch set at v0.61.1

Applied series: numbered unified diffs against the v0.61.1 tag, applied in
lexical filename order with `git apply` by `tooling/tools.sh`. Build fails
loudly if any patch fails to apply.

| patch | audited sites | change |
|---|---|---|
| `001-pkginfo-header.patch` | Drop the `# Generated by melange` comment from `controlTemplate` (`.PKGINFO` starts at `pkgname`); update the control-template test fixtures. |
| `002-slsa-identities.patch` | Builder ID → `https://g5d.dev/containers/builders/melange/v1`; build type → `https://g5d.dev/containers/buildtypes/melange/v1`. Real run timestamps (`StartedOn`/`FinishedOn`) kept. |
| `003-sbom-canonical-package.patch` | New `pkg/sbom/canonical` package: stdlib-only RFC 8785 canonical JSON + deterministic g5d.dev SPDX namespace scheme, with official RFC 8785 test vectors as Go tests. Byte-identical (modulo package clause) with the apko patch copy. |
| `004-sbom-document-identity.patch` | `Organization: Greboid` in document creators; namespace = `https://g5d.dev/containers/sbom/spdx/packages/<sha256 of RFC 8785 canonical JSON of the doc minus documentNamespace>`; deterministic ordering of `hasExtractedLicensingInfos`; `ToSPDX` returns an error; regenerate SBOM goldens. |
| `005-sbom-upstream-source-license.patch` | `SBOMPackageForUpstreamSource` fetch branch: set `LicenseDeclared: licenseDeclared` on the upstream-source SPDX entry. Upstream drops the parameter for fetch pipelines, so the source entry defaulted to NOASSERTION ("no license specified" warning); the git-checkout branch already propagated it. |
| `006-bwrap-guest-modes.patch` | `bubblewrapOCILoader.LoadImage` re-asserts each entry's stored layer mode after extraction: `os.MkdirAll`/`os.OpenFile` apply the umask, and the existing correction only restored setuid/setgid/sticky, so world-writable directories (golang-builder's shared `/go`) landed as 0755 in bwrap guests. Both directories and regular files now get an explicit `Chmod` to the stored mode. |
| `007-forgejo-update-monitor.patch` | New `forgejo:` update monitor in `pkg/config` (`instance` + `identifier`, strip/tag filters, `use-tag`), its `VersionHandler` methods, `replaceUpdate` var substitution, an `UPDATE.md` section, and a config parse/substitution test. Config loading is `KnownFields(true)`, so recipes using `update: forgejo:` (forgejo, forgejo-runner) fail every build without it. melange itself never queries update sources — the block is consumed by update tooling (depbot). |

Not a patch file: `tooling/tools.sh` replaces melange's `chainguard.dev/apko`
module dependency with a tree at the exact version melange pins
(v1.4.3), carrying `tooling/apko/patches/007-index-head-405-fallback.patch`.
melange resolves build guests through apko's in-tree apk client from the
module cache, which the standalone-apko patch series otherwise never
reaches; without it, remote index resolution dies on servers that answer
405 to the etag-probe HEAD (Forgejo Alpine endpoints). Patching the pinned
version keeps the module graph and go.sum untouched.

Every step compiles and the upstream test suites pass after the series.
Rebase notes: goldens under `pkg/build/testdata/goldenfiles/sboms/` are
content-derived and must be regenerated with the rebased code.
